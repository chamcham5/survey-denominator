# 分母と回答行の比較

同じ設問の「75%」と「60%」を、算術・分母方針・採用した行IDから確かめる無料ブラウザーツールです。

**[無料ツールを開く](https://hitocase.itch.io/survey-denominator)** → `Run tool` → 自分の匿名行入力 → 比較票を全行コピー。インストール・登録・ファイル保存は不要です。

## このソースを読む方へ

選択式アンケートの集計を説明する画面や手順を検討していて、回答済み・欠測・未質問の区別、分母方針と計算結果、採用した行IDの対応を確認したい実装担当者向けです。タブ区切りの入力から比較票ができるまでを確認できます。

- `model.js`：タブ区切り3列と明示条件を計算入力へ変換します。空欄から状態や分母方針を推測しません。
- `business.js`：分母・割合・採用行と算術の比較を計算します。
- `app.js`：算術の一致と方針差を分けて表示し、全行の比較票を用意します。
- `index.html` / `style.css`：無料の入力・結果画面です。

ソース閲覧や配布数は、実装者の到達・顧客試用・支払意思・時間短縮の証拠ではありません。既存の表計算や調査サービスで完結する場合もあります。

## 75%と60%の合成例

「はい」が6行、「いいえ」が2行、欠測が2行なら、回答済み8行を分母にして75%、全10行を分母にして60%。両方の算術が合う場合も、宣言した分母方針とは違う場合があります。画面の合成例で、採用した行の違いを確認できます。実顧客の成果ではありません。

自分の入力では、1設問の選択肢とタブ区切り3列を明記します。たとえば次は欠測・未質問を区別した架空の表です。

```tsv
row_id	state	selected
example1	answered	Y
example2	missing	
example3	not_asked	
```

選択肢をYとN、確認する選択肢をYとし、分母を対象行（未質問を除く）にすると1/2、全行なら1/3になります。未記載の方針や空欄の意味は推測しません。列の書式と出力の割合/分母を確認する準備は利用者側に必要です。

## 無料で完結する範囲

単一・複数回答の1設問、最大1000回答/選択肢50個。画面の表は先頭200行ですが、比較票は全行の採用IDを含み、選択してコピーできます。分母0は0%ではなく未算出。2つの元ファイルの母集団やID対応、重み付け、欠測補完、科学的妥当性、統計的有意差は検証しません。

ツールの入力はブラウザー内で処理し、ツールから外部送信・解析・自動保存しません。合成・匿名化データ専用です。氏名・個人属性・健康情報・顧客情報・秘密情報・自由記述は入力しないでください。自動匿名化は行いません。再読込や終了で入力は消えます。

## 任意の有料追加作業

既知の列名・状態コードに合わせるCSV整形や複数設問の確認票が必要な場合だけ、[配布ページ](https://hitocase.itch.io/survey-denominator)のコメント欄で見積もりを相談できます。無料結果の取得に購入・相談は不要です。コメントは公開され、itch.ioへのログインが必要です。公開可能な希望列構成・設問数・回答件数だけを記載し、原票・回答行ID・個人情報・秘密情報・連絡先を投稿しないでください。

料金・納期・可否・扱える情報は運営者が個別に確認します。投稿だけで契約や決済は成立しません。未記載の分母方針や回答状態を自動で補う仕事は含みません。
